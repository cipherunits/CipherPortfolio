# 05 — Development and Commands

## Prerequisites

- Node.js 20+
- pnpm 9+

## Install

```bash
pnpm install
```

## Run Dev Server

```bash
pnpm dev
```

Default URL: `http://localhost:3000`

## Build and Start

```bash
pnpm build
pnpm start
```

## Lint

```bash
pnpm lint
```

## Environment Variables

Example keys used in docs and UI:

- `CONTACT_EMAIL`
- `GITHUB_API_BASE_URL`
- `GITHUB_ACCESS_TOKEN`

Set them in `.env.local` for local development.

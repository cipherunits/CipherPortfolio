# 01 — Project Overview

## Purpose

`CipherPortfolio` is the official portfolio website for Cipher Unit.

It presents:

- brand identity
- highlighted project(s)
- technical skills
- contact channels

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- ESLint 9
- pnpm

## High-Level Features

- responsive landing page sections
- dedicated contact page (`/contact`)
- external redirect page to GitHub (`/github`)
- custom 404 page
- SEO metadata + sitemap + robots

## Directory Summary

- `src/app` → routes, layout, metadata, sitemap
- `src/components` → UI and section-level components
- `public` → static images and `robots.txt`

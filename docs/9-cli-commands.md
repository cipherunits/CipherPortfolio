# 9 — CLI

## pnpm

```bash
pnpm install
pnpm dev
pnpm build
pnpm start
pnpm check
pnpm lint
pnpm typecheck
pnpm clean
pnpm seo:notify
```

## Make

```bash
make install
make dev
make build
make start
```

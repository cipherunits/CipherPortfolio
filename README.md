## 🚀 Quick Start

```bash
git clone https://github.com/cipherunits/CipherPortfolio.git

cd CipherPortfolio

make install
make dev
```

or

```bash
pnpm install
pnpm dev
```

Open:

```
http://localhost:3000
```

---

## 📦 Production

```bash
make build-app
make run
```

or

```bash
pnpm build
pnpm start
```
